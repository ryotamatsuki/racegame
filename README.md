# racegame

ミニ四駆の機種とパーツを選び、改造したマシンで競う3Dブラウザゲームのプロジェクトです。

**現在は仕様策定済み、ゲーム実装前です。**
このリポジトリにゲーム本体やデプロイ済みサイトが存在することを示すものではありません。

## 設計資料

- [ゲーム仕様書](docs/GAME_SPEC.md)：画面、機種、パーツ、走行、素材、スマホ対応、公開、受入試験。
- [生成AI向け詳細実装プロンプト](docs/IMPLEMENTATION_PROMPT.md)：実装から検証、GitHub Pages公開までの指示。

## 予定する完成版

- 独自4機種と9カテゴリのパーツ交換。
- 回転、ズーム、分解展示、部品拡大ができる3Dガレージ。
- CPU3台との3周レース、3コース、5カメラ視点。
- 改造を反映する走行モデル、タイムアタック、端末内セーブ。
- 日本語、PCとスマホへの対応。
- Three.js、TypeScript、Vite、Reactによる静的ブラウザアプリ。

公開予定URL：https://ryotamatsuki.github.io/racegame/
